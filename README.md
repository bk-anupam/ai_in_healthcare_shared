## Working with this repository

Open notebooks in Jupyter or a compatible notebook environment. Follow each notebook’s dataset and dependency instructions; the project starter has its own requirements file. Keep submitted paths and submission branches stable to preserve course links.

Use a separate branch for each lab or project change. Include the lab identifier and a short summary in each commit. This repository contains educational experiments, not a validated clinical application.
